# SlurryCalc — калькулятор составов суспензий для литий-ионных аккумуляторов

Android-приложение (Kotlin + Jetpack Compose, Material 3) для расчёта навесок
компонентов при приготовлении электродных суспензий.

## Возможности

- **Пресеты составов**: типовой катод (96/2/2 AM/Super-P/PVDF в NMP, СО 50 %)
  и анод (95/2/1.5/1.5 графит/Super-P/CMC/SBR в воде, СО 45 %).
- **Произвольный состав твёрдой фазы**: добавление/удаление компонентов,
  задание истинской плотности (г/см³) и массовой доли (%). Встроенная база
  материалов: LCO, NMC 532/622/811, LFP, LMO, NCA, PVDF, Super-P, CMC, SBR,
  графит, Si, LTO, Al₂O₃.
- **Растворитель**: пресеты NMP и вода (плотность и вязкость при 25 °C),
  возможность задать свои значения.
- **Сухой остаток** (массовая доля твёрдых, %).
- **Задание партии** в одном из трёх режимов: масса суспензии (г),
  масса сухого вещества (г) или объём партии (мл).
- Расчёт выдаёт:
  - массы каждого компонента и растворителя для навески;
  - плотность суспензии и истинскую плотность сухого вещества;
  - объём партии и объёмную долю твёрдой фазы φ;
  - ориентировочную оценку вязкости по моделям Муни / Марона–Пириса /
    Кригера–Догерти (точность порядка ±2×, предназначена для подбора СО);
  - предупреждения (нормализация долей, слишком высокий φ, неприменимость модели).

## Структура проекта

```
app/src/main/java/com/slurrycalc/
  engine/SlurryEngine.kt   — модель расчёта (без зависимостей от Android)
  ui/SlurryViewModel.kt    — состояние экрана
  ui/MainActivity.kt       — интерфейс (Compose, Material 3)
```

## Сборка

Требуется Android SDK (compileSdk 34, minSdk 24). Откройте проект в Android Studio
(проект сконфигурирован под AGP 8.5 / Gradle 8.7) либо соберите из командной строки:

```bash
sdkmanager "platforms;android-34" "build-tools;34.0.0"
gradle wrapper          # сгенерирует gradlew (в репозиторий бинарные файлы wrapper не включены)
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Формулы движка

- ρ_сухого = 1 / Σ(wᵢ/ρᵢ) — правило смещения для истинских плотностей
- m_р-ля = m_сухого · (1 − DC)/DC
- φ = V_твёрдых / V_суспензии (идеальное смешение объёмов)
- η_rel (Муни) = exp([η]·φ / (1 − φ/φ_max)), [η] = 2.5, φ_max = 0.74
- η_rel (Марон–Пирис) = (1 − kφ)⁻²; η_rel (Кригер–Догерти) = (1 − φ/φ_max)⁻ᵏ
